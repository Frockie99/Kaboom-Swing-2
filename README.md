# Kaboom-Swing-2
Unofficial Sequel to Alessandro Pezzetti's "Kaboom Swing"

Link to the game design document:
https://docs.google.com/document/d/1H3tILOcaT9jVdD8iFzlVcaAAMTLT0tO90NcgDf7PSe8/edit?usp=sharing

###The naming convention will follow the following rules:
e.g. 1.2.3.4
1 will follow entire game changes/reworks, until the game is released, it will be 0
2 for major updates that adds or majorly changes the game
3 for smaller updates; tweaks or smaller additions
4 for any other minor changes in the github such as line tweaks or very minor bug fixes
